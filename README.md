# Quản lý giảng viên - QLHocPhan

Ứng dụng PHP + MySQL cho bài tập quản lý giảng viên.

## Cài đặt nhanh

1. Khởi động Apache và MySQL trong XAMPP.
2. Mở phpMyAdmin và chạy file `database.sql` hoặc tạo database `QLHocPhan` bằng giao diện.
3. Đưa thư mục này vào `C:\xampp\htdocs\ThiGiuaKi`.
4. Truy cập: `http://localhost/ThiGiuaKi/index.php`

## Chức năng

- Thêm dữ liệu giảng viên
- Hiển thị danh sách giảng viên
- Sửa thông tin giảng viên
- Xóa giảng viên
- Giao diện responsive
- Hỗ trợ tải ảnh lên hoặc dùng link ảnh
